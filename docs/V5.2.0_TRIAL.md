# FileScope 5.2.0 Windows試用候補

## 起動と切り分け

ZIPの全内容をローカルの空フォルダーに展開し、同じフォルダーの FileScope.exe を直接起動する。_internal はEXEの隣に置く。

配布EXEのPEサブシステムはWindows GUI（値2）。OCR確認ではTesseractをコンソールなしで起動し、バージョンと利用言語の取得にそれぞれ5秒の制限を設けた。OCR確認とSQLite索引のオープン・整合性検査は画面表示後のワーカーで実行する。準備中の検索要求は待機し、中断できる。一時ファイル整理も起動前の処理から外した。

通常の遅延を調べる場合、ショートカットのリンク先を確認し、同じ配布物をZIP内からの直接実行や同期中の場所を避けてローカルに完全展開して比較する。今回確認したデスクトップ等の直下にはFileScopeのショートカットが見つからず、報告時に使われたリンク先は未特定。起動時に何も表示されない場合は、クリック時刻とタスクマネージャーでFileScope.exeが現れた時刻を記録する。ローカルログの startup settings、startup ready、startup services でPython起動後の区間を確認できる。ログの起動計測行は検索語や検索パスを記録しない。

同一PCで通常の直接起動を各3回実施。プロセス開始から最初のウィンドウ検出までの中央値はv5.1.1が432 ms、比較版のTkライトが468 ms、最終候補が374 ms。候補の実測範囲は355〜1,040 ms。ディスクキャッシュは消去していない。実環境の30秒超の遅延は再現していない。言語確認を31秒待たせる模擬Tesseractでは、候補は331 msで画面を表示し、OCR確認は約5.17秒で終了した。プロセス残留はなかった。

## 検索と表示

合成テキスト1万件の全件ヒット、索引とCSV自動保存を無効にしたソース版計測を各3回実施。Windows上のTkメインループを使用した。

| 指標の中央値 | v5.1.1 | 5.2.0候補 |
| --- | ---: | ---: |
| 検索開始からGUI完了 | 3.94秒 | 3.71秒 |
| 40 msタイマー間隔 p95 | 86.1 ms | 59.1 ms |
| 各回のタイマー最長間隔 | 114.8 ms | 68.0 ms |
| ピークワーキングセット | 64.7 MiB | 65.8 MiB |

正式版の初回は17.30秒の外れ値を観測。全実行で一致数は1万件。直近のTkライト比較記録は3.86秒、p95 68.2 ms、66.2 MiB。計測セッションが異なるため参考値。実SMB、OneDriveの未取得配置、Defenderの寄与、実Office大容量文書、物理マウスの連続操作、高DPIは未確認。
