# FileScope V5 実機受け入れテスト（約10分）

このテストは **あなたのPC（Tesseract・OneDrive/SharePoint・SMBがある環境）** で実施してください。
Codex側の環境ではクラウドや実Tesseractを再現できないため、ここだけは手元での確認が必要です。

## 準備（2分）

1. `FileScope-v5.0.0-rc1-win64.zip` を任意のフォルダへ展開（例: `C:\Tools\FileScope`）
2. `FileScope.exe` をダブルクリック
3. 右上の「診断」ボタンを押し、`全部コピー` で結果を控える

確認:

- [ ] 起動した（ウイルス警告が出た場合は「詳細情報」→「実行」）
- [ ] ウィンドウタイトルが `FileScope 5.0.0`
- [ ] 診断に `Tesseract : C:\Users\<you>\AppData\Local\Tesseract-OCR\tesseract.exe` が出る
- [ ] 診断の `OCR状態` が `OCR利用可: 日本語+英語`
- [ ] `FTS5 : OK` / `FTS5 trigram : OK`

結果: `PASS / FAIL` ______  メモ: ______________________

## Test A: 通常の Excel / PDF 検索（1分）

1. 検索場所に、ExcelとPDFが入ったフォルダを指定
2. 検索語に、Excelのセルにある語（例: `耐久`）を入れて検索開始
3. 結果の行をクリックし、右のプレビューにセル番地が出ることを確認

- [ ] Excelのセル内容でヒットした
- [ ] PDFの本文でヒットした
- [ ] 一致条件とHit数が表示される
- [ ] `種類` 列が `Excel` / `PDF` になっている

結果: `PASS / FAIL` ______

## Test B: スキャンPDFのOCR（2分）

1. 紙をスキャンしたPDF（文字を選択できないPDF）を用意
2. 詳細設定で `PDF OCR = 自動`、検索モード `標準`
3. そのPDFに載っている語（例: 型番や見出し）で検索

- [ ] 結果にそのPDFが出る
- [ ] 場所が `1ページ [OCR]` のように `[OCR]` 付きで表示される
- [ ] もう一度同じ検索をして、2回目が明らかに速い（OCRキャッシュ）
- [ ] 検索式に `ocr:true` を入れると、そのPDFだけに絞れる
- [ ] 日本語が文字化けせずにプレビューへ出る

結果: `PASS / FAIL` ______

## Test C: OneDrive / SharePoint オンライン専用（2分）

1. OneDriveの「オンライン専用」ファイルがあるフォルダを検索場所にする
2. 検索モード `高速` で検索 → 状態表示の `Online-only skip` が0より大きいこと
3. モードを `標準` に変えて、その資料に載っている語で検索

- [ ] 高速モードで大量ダウンロードが起きていない（タスクバーのOneDriveが静か）
- [ ] 結果一覧に `☁ Online` が表示される（Source列）
- [ ] 標準モードでは、必要な分だけ取得してヒットする
- [ ] FileScopeがOneDriveの設定（Always keep / Free up space）を変えていない

結果: `PASS / FAIL` ______

## Test D: SMB共有フォルダ（1分）

1. 共有フォルダ（`\\server\share` またはマップドライブ）を検索場所にする
2. Excel/PDFの既知語で検索
3. 結果を右クリック → `開く` / `フォルダを開く` / `Excelの該当セルを開く`

- [ ] 共有フォルダのExcelでヒットした
- [ ] ファイルが開く（Excelが起動する）
- [ ] `Excelの該当セルを開く` で該当シート・セルへ移動する（Excel未導入でもファイルは開く）
- [ ] 検索後、`%TEMP%\FileScope-staging` が空になっている

結果: `PASS / FAIL` ______

## Test E: 索引（1分）

1. 詳細設定で `インデックス: 使用する / 1GB`
2. 同じ語で2回検索し、状態行の `索引` と `実読込` を見る
3. ヒットしたテキストファイルの中身を書き換えて、再度検索

- [ ] 1回目と2回目で結果件数が同じ（Hit/No Hitが変わらない）
- [ ] 2回目は `索引` が増え、`実読込` が0に近づく
- [ ] 内容変更後、新しい語でヒットする
- [ ] 変更前の語はヒットしない（古い索引が残っていない）

結果: `PASS / FAIL` ______

## 追加の異常系（余裕があれば）

- [ ] 0バイトファイル、拡張子だけ `.xlsx` の偽ファイル、パスワード付きPDF を置いて検索しても落ちない
- [ ] ファイル名に日本語・記号・非常に長い名前があっても検索結果に表示される

- [ ] 検索式 `AAA & (BBB` を入れたとき、スタックトレースではなく日本語のエラーが出る
