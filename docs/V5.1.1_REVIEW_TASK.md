## レビュー範囲（v5.1.0 = 前回の変更）

`git diff 58b9e9e eac9089 -- filescope tests scripts` が今回の変更です。
重点は次の4点です。

1. **索引検索の `_index_lock`（`filescope/core/coordinator.py`）**
   - 直列化によってファイルの取りこぼし・二重処理・判定の変化が起きないか
   - 既存の `self._lock` とのロック順序、デッドロック、飢餓の可能性
   - `coverage` カウンタ、`_cleanup_index`、`_emit_result` への影響
2. **SQLite アクセス（`filescope/index/database.py` `iter_chunks` / `_to_chunk`）**
   - チャンクの `text` / `kind` / `location` / 順序が変わらないか
   - 未知の `kind`、sqlite から返る非 `str` 値（`bytes` 等）の扱い
   - スレッドからの同時アクセス（1コネクション共有）が安全か
3. **キャンセル**
   - キャンセルが全ワーカー・PDFレーン・列挙に伝わるか、応答が早いか
   - キャンセル時に結果・索引・カウンタが壊れないか
4. **結果一覧の更新処理（`filescope/ui/main_window.py`, `filescope/ui/preview.py`）**
   - `_list_refresh_due`（400 ms 間引き）で結果が永久に表示されないことがないか
   - `_wake_drain` / `DRAIN_ACTIVE_MS` / `_fill_window` の選択復元 / `_on_select` の
     早期 return が、結果の非表示・UI停止・終了後のタイマー発火を招かないか
